# KirDev Studio — Compliance & Security Audit Tasks

Дата: 2026-10-22. Статус: **предварительный аудит; НЕ подтверждение юридической или технической безопасности**.

Этот файл — задания для Claude Code/Codex, а не перечень доказанных нарушений. Первичный обзор включал деревья файлов всех 11 репозиториев и выборочное чтение конфигураций, документации и исходников. Полный построчный аудит, проверка истории Git, сборки и автоматические сканеры **не выполнены**.

## Правила для ИИ-агента
1. Начни с инвентаризации всех файлов, зависимостей, бинарников, лицензий и истории Git. Разделяй VERIFIED / SUSPECTED / NOT_CHECKED; каждую находку подтверждай путём файла, строкой и воспроизводимой проверкой.
2. Никаких удалений, force-push, переписывания истории, ротации ключей, изменений лицензий, публичных релизов или деплоя без отдельного согласования владельца.
3. Не удаляй авторство, LICENSE, NOTICE и права сторонних авторов. Собственная лицензия не отменяет лицензии upstream и зависимостей. Проверяй совместимость и условия API по первоисточникам.
4. Не выводи реальные секреты в отчёты, логи, коммиты и ответы. При обнаружении действующего секрета сообщи только тип, путь и план отзыва/замены.
5. Проверяй поведение, а не только текст политики: данные, сеть, логи, сроки хранения, разрешения, админ-доступ, безопасность сборок.
6. Исправления делай маленькими коммитами в отдельной ветке; добавляй тесты. Не изменяй функциональность без согласования.
7. Отчёт должен содержать: риск, доказательство, возможное влияние, исправление, тест проверки, остаточный риск, ссылку на требования лицензии/платформы. Не обещай «100% безопасность».
8. Если требуется правовая интерпретация лицензии или законодательства Казахстана, отметь как LEGAL_REVIEW_REQUIRED, а не делай категорическое заключение.
